Create a 90-minute university-level Operating Systems class about [TOPIC].

The students already understand basic C programming and basic Linux commands, but assume they are learning this Operating Systems topic for the first time.

The class should be practical and technically accurate.

Include:

- Learning objectives
- A 90-minute lesson plan with estimated time for each section
- Motivation: explain why this topic is important in real operating systems
- Theoretical explanation of the main concepts
- Important terminology students should know
- At least 2 diagrams to help visualize the concepts
- C examples that can be compiled and executed on Linux
- Required C headers
- Commands to compile the programs with gcc
- Commands to execute and inspect the programs
- Explanation of the expected output
- Mention when program output may be nondeterministic
- Linux commands or /proc examples related to the topic
- 3 questions to ask students during class
- 2 short programming exercises students can attempt during class
- 1 homework programming assignment
- Common mistakes or misconceptions
- A short summary of the most important concepts at the end

For every C program, explain what happens step by step, not only what the code does.

Prefer small programs that can be demonstrated live in a Linux terminal.
